# Cumulative maintenance review

Apply these six criteria at each stage using the active request and still-supported earlier contracts. Accept alternative correct designs; no specific helper, storage model or patch shape is required.

1. **Correctness:** Enrollment, FIFO ordering and capacity agree with the active contract. At stage 1 cancellation promotes; at stage 2 pauses defer promotion; at stage 3 offers reserve capacity and acceptance alone makes waiting employees attend. Check failed operations leave data intact.
2. **Migration and consumer consistency:** The real JSON submission caller validates the optional field and returns the correct status/error; attendance excludes waitlisted and offered entries. At stage 3 inspect cancellation and reopen paths for obsolete automatic confirmation, including multiple free seats. Earlier tests should be updated where their behavior is explicitly retired.
3. **Established policy reuse:** Session lookup precedence, canonical directory identities, duplicate detection and domain-error translation remain consistent across old and new entry points. New offer operations must follow the same identity and error conventions.
4. **Proportional maintainability:** Trace enroll, cancel, admissions reopening, acceptance and decline. State changes should remain understandable and consistent across these concrete paths. Assess cumulative burden from contradictory capacity decisions or obsolete promotion behavior, never line count alone. Preserving an export or compatibility path is not a defect unless it contradicts a stage contract or creates a demonstrable maintenance burden.
5. **Type and check integrity:** Strict compilation and baseline plus stage-appropriate tests pass without weakening compiler settings, suppressing meaningful errors, or treating untrusted portal JSON as trusted domain data. Internal types should represent current statuses and roster fields accurately.
6. **Independent evidence:** Tests exercise public desk operations and actual portal/attendance callers, including normal flows, meaningful failures, FIFO across pauses, capacity reservations and detached snapshots. Evidence should distinguish behavior from implementation details and include the stage 3 retirement of automatic confirmation. Hidden graders supplement rather than replace review and solver tests.
