The coordinator needs to pause admissions while arranging trainers, without losing a session's waiting list.

Add `TrainingDesk.setAdmissions(sessionId, open)` and expose `admissionsOpen` on its roster; new sessions start open. While closed, every new enrollment request (including waitlist opt-ins) fails with ADMISSIONS_CLOSED. For an existing session this check takes precedence over email or duplicate checks. The portal returns that domain error using its usual failure reply.

Cancellation remains available during a pause, but no waiting employee is promoted until admissions reopen. Reopening fills all available seats from the waiting list in FIFO order. Setting the same state again is harmless. If an open session has a backlog, a new arrival cannot take a seat ahead of that backlog. Session isolation, attendance, waitlist opt-in rules and the other existing contracts still apply. Add tests for pause/cancel/reopen flows.
