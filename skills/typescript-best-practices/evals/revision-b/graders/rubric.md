# Frozen rubric — six criteria

Evaluate behavior and types; accept equivalent designs. Runtime groups are supporting evidence, not a replacement for reviewing the public contract.

1. **Correctness:** Only eligible products contribute to the promotion base and minimum threshold. Include quantities and repeated SKUs, use the full subtotal for the final total, and preserve line order. Use `eligible-base-and-minimum` and `line-order-and-quantities`.
2. **Public API and type accuracy:** CartQuote exports a required numeric `eligibleSubtotalCents`, available to typed consumers and present on every quote, including empty carts and unknown/omitted codes. Preserve all existing public signatures and result fields. Use `public-field-and-no-code` plus source/typecheck review.
3. **Existing policy reuse:** Preserve shared safe monetary arithmetic, combined-base rounding, promotion caps and minimum boundary semantics. Use existing policy helpers or an equivalent shared policy path. Zero discounts retain null appliedCode; code matching remains exact. Use `rounding-cap-and-boundaries` and `existing-errors-and-range-policy`.
4. **Maintainability:** Eligibility is derived from catalog records while pricing the requested lines, or through another coherent approach without conflicting eligibility or monetary rules. Accept equivalent designs. Deduct for concrete costs such as duplicated promotion rounding, mutable cross-request aggregates or an unrelated promotion framework. No required syntax, traversal count or line count.
5. **Failure and ownership semantics:** Keep synchronous validation/unknown-SKU/overflow errors even without a known promotion; preserve catalog snapshots/copies and independent quote lines without mutating caller values. Use `existing-errors-and-range-policy` and `catalog-and-quote-ownership`.
6. **Evidence:** Typecheck/build and existing visible tests pass. Added or updated regression tests demonstrate mixed eligibility, threshold reached versus missed, combined-base rounding/cap behavior, and unknown/omitted codes reporting the base. Equivalent reproducible evidence is accepted; no prescribed test layout. Claims must match actual results.
