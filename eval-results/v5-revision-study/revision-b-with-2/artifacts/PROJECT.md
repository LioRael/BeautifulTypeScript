Runtime: Node 22 ESM. TypeScript 5.9.3; no runtime dependencies. Run npm run typecheck and npm test. Source imports use .js extensions. Catalog and CartPricing form the public API. model.ts exports the public data types; policy.ts owns validation, safe amount addition and promotion rounding/caps.

Amounts are nonnegative safe integer cents. Quantities are positive safe integers. Catalog validates and snapshots products/promotions on construction and returns copies. Product SKU and promotion code keys are nonempty and unique by configuration. Matching is exact and case-sensitive. Products may cost zero. A promotion cap may be zero. All public inputs are structurally typed; malformed containers or nonboolean eligibility flags are outside the contract. Invalid quantities, unknown SKUs and unsafe monetary products/sums throw synchronously, including when a promotion is unknown or omitted. Do not silently clamp invalid amounts. Existing error text is public.

Cart lines are not consolidated; repeated SKUs are valid and remain separate. Cart inputs belong to the caller. Quote arrays and line objects belong to that quote and must not alias inputs or later quotes. There is no mutable cart state, persistence or cache. Tests import built dist modules.
