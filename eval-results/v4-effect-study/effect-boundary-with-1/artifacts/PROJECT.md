Any invalid field invalidates the whole batch with {ok:false,error:"invalid-batch"}; partial acceptance is not supported. Unknown properties are ignored.

Output contains only sensorId and readings; each output reading contains only atMs and celsius. Convert F using (value - 32) * 5 / 9; do not round. C values are unchanged. The caller owns the input and may mutate it after decoding. Successful output must be independent of input arrays and objects; decoding must not mutate input. The trusted domain helper temperatureRange receives a valid nonempty SensorBatch.
